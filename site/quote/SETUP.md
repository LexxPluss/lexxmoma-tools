# LexxMoMa 3D 見積 — 見積依頼の受け口のセットアップ

お客様が 3D 見積で組んだ構成と、希望の販売経路(LexxPluss と直接 / SIer と / 商社・販売店を通して)・お付き合いのある SIer・連絡先を
LexxPluss の Google スプレッドシートに 1 行ずつためる設定です。
設定するまでは「テストモード」で動きます(送信ボタンを押しても届かず、画面にテストモードと表示されます)。

仕組みは見学ツアーのアイデアボード(`library/board/SETUP.md`)と同じです。GitHub Pages は書き込みを受け取れないため、受け口だけ Google Apps Script にします。

## 手順(10 分ほど)
1. Google ドライブで新しいスプレッドシートを作る(名前例: `LexxMoMa3D見積_見積依頼`)。**社外に共有しない**(連絡先を含むため)
2. メニュー「拡張機能 > Apps Script」を開き、最初からあるコードを消して `apps-script.gs` の中身を貼り付ける
3. 依頼をメールで受け取りたい場合は、先頭の `NOTIFY_TO` に宛先を書く(例: `'sales@lexxpluss.com'`)。保存
4. 右上「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ 初回は権限(スプレッドシート・メール送信)の承認を求められるので許可する
5. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`)をコピーし、
   `quote/catalog.js` の `QUOTE_CONFIG.endpoint` に貼り付けて PR を出す
6. 公開後、3D 見積で試しに 1 件送り、シート `requests` に行が増える(と通知メールが届く)ことを確かめる

> 会社の Google Workspace の設定で「アクセスできるユーザー: 全員」を選べない場合は、管理者に匿名アクセスの許可を依頼してください。

## 運用
- `status` 列: `new`=未対応 / `doing`=対応中 / `done`=見積送付済み / `spam`=いたずら
- 受付番号(`Q-yyMMdd-XXXX`)はお客様の画面にも表示される。問い合わせの際の照合に使う
- コードを直したら「デプロイ > デプロイを管理 > 編集 > 新バージョン」で更新(URL は変わらない)

## 集めている項目
| 列 | 内容 |
|---|---|
| company / dept / name / email / tel | 連絡先(会社名・お名前・メールは必須) |
| timing | 導入時期の目安(任意) |
| channel | 希望の販売経路: LexxPluss と直接 / SIer と / 商社・販売店を通して / 未定・相談(必須)。価格は経路で変わらない。窓口を決めるために使う |
| partner / partnerContact | SIer 経由・商社経由のときの相手先の会社名・担当者(任意) |
| sierRelations | お付き合いのある SIer・設備メーカー(任意) |
| message | ご相談内容(1,500 字まで) |
| total / body / extra / laterItems / items / terms / catalog | 合計・本体標準価格・別途費用(税別)、ヒアリング後に金額を出す項目の件数、選んだ構成(商品 ID × 数量)、カタログの版 |

IP アドレス・端末情報は保存しない。連絡先はお客様のブラウザにも保存しない(構成の下書きだけ保存)。
