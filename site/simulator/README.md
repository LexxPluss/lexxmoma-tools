# LexxMoMa 動作シミュレーター（Motion Simulator）

営業担当が顧客の工程に対して「どれくらいのサイクルタイムで回るか」を見積もるツール。
2D（上から）の表示で全体のレイアウトと走行を組み、3D 表示でアームの届く高さ・距離と手先の姿勢を確かめる。
公開版: https://lexxpluss.github.io/lexxmoma-tools/simulator/lexxmoma-2d.html
（元は PoC-Code_MoMaCycleTimeSimulator。このリポジトリが正）

## アームのモデル（3D・6 軸）

- 関節配置・リンク長・可動範囲・最大角速度は FANUC 公式の
  `fanuc_crx_description/urdf/crx20ia_l_urdf_macro.xacro` の値（`crx-kinematics.js` の `MODEL`）。
  取付面→J2 245 mm、上腕 710 mm、前腕 540 mm、手首オフセット 150 mm、フランジ 160 mm、最大リーチ 1,418 mm。
- 角加速度は非公開のため「最大速度に 0.4 s で到達」の推定値（2D 版からの前提を踏襲）。
- アーム基準座標は URDF の `wbase`（J1 回転中心・取付面の 245 mm 上、x 前・y 左・z 上）。
  手先の姿勢は FANUC 表記の W/P/R（固定軸 XYZ）。ツール長は FANUC フランジの z 方向。
- アーム取付: 車体中心、床から 750 mm（`ARM_MOUNT_Z`。Output/02 の案、要確認）。車体は 750×600 mm（従来どおり）。
- 取付向き `ARM_MOUNT_YAW` = +90°: J1 = 0° が車体の左を向く。実機は J1 の可動限界（±180°）が車体の右側に来る載せ方のため。
  前 = J1 −90°、後ろ = +90°、右 = ±180°（限界）。手先コントローラと姿勢一覧の座標は車体基準（x 前・y 左）で表示し、IK の目標はアーム基準に直してから解く。
  保存ファイルには `armMountYawDeg` を記録し、無い版（rev.67 以前、J1 = 0° が前向き）は読込時に J1 を回して合わせる。
- 逆運動学は数値解（減衰最小二乗、関節制限内にクランプ）。届かない目標には最も近い姿勢を返し、UI に警告を出す。
- 2D の表示は同じ 6 軸姿勢を上から投影したもの。Shift＋↑↓ の「伸縮」と Shift＋PgUp/PgDn の「上下」は
  手先の姿勢を保ったまま IK で解く。

## 保存ファイルの互換

- `version: 2`（rev.63〜）: `armPoses[].q` と `robot.arm.q` は 6 関節角 [rad]、`toolLen` [mm] を追加。
- `version: 3`（rev.66〜）: 背景の四角・直線・文字を `objects[]` に統合。共通 `id, type, name, visible`。
  `box`（設備・区画）: 中心 `x,y`、向き `yaw`、`w,d,h`、底面の高さ `z0`（0=床に接地）、`color`。`h=0` は床の区画。
  `line`: `x1,y1,x2,y2,color`。`text`: `x,y,text,size,color,vertical`。`image`: 下絵（rev.69〜。それ以前の `bgImage` は変換）。
  旧 `bgRects/bgLines/bgTexts`（rev.65 の `h` 含む）は読込時に変換。
  `test/sample_booth_rev61.json` は旧形式の実例（展示会のレイアウト）で、読込の変換の確認用。
- `version: 4`（rev.70〜）: 車体位置 `bodyPoses` とアーム位置 `armPoses` を、登録した位置 `points[]` に統合。
  `{name, body: {x,y,th}|null, arm: {q:[6]}|null}`（どちらか一方だけも可）。初期状態は `initial: {body, arm}`（それぞれポイント名）。
  ブロックは `{type:"point", point, move:"both"|"body"|"arm", mode, vmax}` と `{type:"other", name, wait}`。
  version 3 以前は読込時に、車体位置を「車体だけ」、アーム位置を「アームだけ」のポイントに、Move Body / Move Arm を
  `move:"body"` / `move:"arm"` の移動ブロックに変える（同じ名前の車体位置とアーム位置は、アーム側に「（アーム）」を付ける）。

## 登録した位置（左ペイン、rev.70〜）

- 左ペインは、上に「位置の登録」（どちらのタブでも使える）、その下に「登録した位置｜アーム操作」のタブ。操作方法と前提値（シミュレートパラメータ）はヘッダーの「ⓘ 操作と前提」のダイアログ
- 「＋ 今の位置を登録」で、今の車体の位置とアームの姿勢を 1 件のポイントにする。チェックを外すと車体だけ・アームだけも登録できる
- 一覧は 1 行 1 件。車体の位置が同じポイントは、場所の見出し（x・y・θ）の下にまとまる。アームだけのポイントは最後の見出しの下
- 行にマウスを乗せると、その位置を半透明の影で重ねる（ロボットは動かさない）。3D では半透明のオレンジのロボット（`setShadow`）
- 行のボタン（「動かす」= 登録してある方をそこへ、「アームだけ」、「編集」）は、マウスを乗せた行と選んでいる行にだけ出す（rev.72〜）。車体だけの位置には「車体だけ」の印。
  上書き・削除は編集欄の下端（「今の位置で上書き」「この位置を削除」）。
- 行の「編集」を押すと左ペインが右へ広がり、その右側に「位置の編集」が開く（✕ 閉じるで元の幅に戻る。開いている間は選んだ行に追従）。
  編集欄はラベル｜入力欄の表: 名前、車体（チェック）・位置 X:Y・向き、アーム（チェック）・手先（表示のみ）・関節 J1〜J6。
  その場で直せる。チェックを入れると今の車体の位置・アームの姿勢が入り、外すとその位置ではもう一方だけを動かす
- レイアウトの設定欄は、ラベルが上で単位が欄の中の入力欄とスイッチ（`inBox`・`fieldBox`）
  見出しのボタン（マウスを乗せると出る）: 「車体を動かす」= 車体だけその場所へ、「今の場所に更新」= その場所のポイントをまとめて今の車体の位置へ移す
- シーケンスの Move ブロック（カードの名前は Move。時間は名前の横に「Move (0.96 s)」。何を動かすかは色と「動かす」で分かる）は、行き先のポイントを選び、「動かす」の Body・Arm のチェックで動かすものを決める（チェックが入っている方を動かす。両方外すことはできない。位置に無い方は選べない）。
  1 段に車体を動かすブロック 1 つ・アームを動かすブロック 1 つまで。車体とアームは同時に動き始め、ブロックの時間は遅い方。
  タイムラインの Move の棒にマウスを乗せると、そのブロックが終わったときの姿勢を 2D・3D に影で重ねる（動かさない方はその段の開始時の姿勢）。
  車体が既にその場所にいるときは車体は動かない（同じ場所の「構え」→「掴み」のような移動はアームだけが動く）

## シーケンスとタイムライン（中央の下、rev.71〜）

- シーケンスは中央の下のタイムラインで組む。横が時間、縦の線のあいだが 1 段、レーンは車体・アーム・その他。
  段は左から順に動き、同じ段のブロックは同時に動き始める。棒の長さがブロックの時間で、斜線（ピンク）はもう一方を待っている時間（段の時間は遅い方）
- 段をクリックで選ぶ（もう一度で外す）。選んだ段の設定（ブロックのカード、同時に動くブロックの追加、◀ ▶ の並べ替え・複製・削除）は右ペインの「シーケンス」タブに出る。
  一番上は開始位置（初期状態）
- 段を左右にドラッグで並べ替え（青い縦線の所に入る）。末尾の ＋ で空の段、見出しの「＋ Move」「＋ その他」で、選んでいる段の後ろ（なければ最後）にそのブロック 1 つの段を足す
- 上の目盛りの帯か赤い線をドラッグすると、その時刻の姿勢に飛ぶ（一時停止の扱い。「▶ 再開」で続きから、「⏹ リセット」で再生前の姿勢へ）
- 「時間比例」は棒の長さが時間に比例（短すぎる段は最小幅）、「等幅」はどの段も同じ幅。－／＋（Ctrl＋ホイール）で拡大して横にスクロール。選んだ表示はブラウザに覚える
- 一番下は内訳の棒（アームだけ・車体だけ・同時に動く・その他・待ち）。合計はヘッダー、表の形の内訳は右ペインの「トータル時間」
- 再生・リセット・録画・再生速度はタイムラインの見出しの行。3D の視点の切替などは 3D 表示のときキャンバスの右下に出る
- キャンバスとタイムラインの境目を上下にドラッグすると、レーンの高さが変わる（ダブルクリックで元の高さ。ブラウザに覚える）（rev.72〜）

## ヘッダーと名前のラベル（rev.72〜）

- サンプル・設定保存（Ctrl+S）・設定読込はヘッダーの「📁 ファイル」メニューにまとめた。幅 1360 px 以下では「使い方」「操作と前提」を記号だけにし、
  時間の見出しを「経過 / 合計」に縮めて、ヘッダーが 1 行に収まるようにしている（1100 px 以下では LexxMoMa の文字も隠す）
- 2D の登録した場所の名前は、画面で近い（向きだけ違う）場所を 1 つにまとめ、ほかの名前・ロボットと重なるならずらし、それでも重なるなら書かない
  （`drawLocLabels`）。マウスを乗せている場所（オレンジ）と選んでいる位置の名前は必ず出す。名前には白い縁取り
- 3D の名前のラベルは画面上で一定の大きさ（13 px。`sizeAttenuation: false`、`updateLabelScale`）。近い場所の名前は 1 つにまとめる

## レイアウト（右ペインのタブ）

- 描くツールは 2D キャンバス左端の縦ツールバー（選択 V・箱 B・区画 Z・直線 L・文字 T・下絵 I）。箱・区画・直線はドラッグで描き、
  文字はクリックで置く。描いたら選択ツールに戻り、描いた物が選ばれる。ツールの設定（色・高さ・文字）はキャンバス上部の帯に出る。
  選択ツールでは物の上のドラッグで移動、何も無い所のドラッグで画面移動。選択ツール（V）は最初は OFF で、押すと ON、もう一度押すと OFF になる。OFF のときは、
  ドラッグは常に画面移動、クリックしても物を選ばない（選択も外れる）。3D 表示中に描くツールを押すと 2D に切り替わる
- 右ペインは「シーケンス」「レイアウト」のタブ。レイアウトのタブは一覧（種類で絞り込み、複製・削除・表示切替、行ごとの 🔒 ロック）と
  選択中の設定（名前・色・位置・向き・寸法・高さ・床に接地／底面の高さ）
- 背景画像は `type: "image"` の「下絵」オブジェクト（`objects[]` の 1 要素。`src`(dataURL)・`pxPerM`・中心 `x,y`・`opacity`）。
  何枚でも置ける。読み込んだ直後はロック済みで、キャンバスでは選べず動かない（全体を覆うので誤選択を防ぐ）。
  動かすときは一覧の 🔒 を外す。縮尺合わせ・中心 X:Y・透明度・差し替えは設定欄。旧形式の `bgImage`（1 枚）は読込時に変換
- ロック中のオブジェクトはキャンバスの当たり判定から外れる（一覧からは選べる）。保存形式は各オブジェクトに `locked` が加わるだけ
- 選択は一覧、2D のクリック（何もしていない時／選択・移動モード）、3D のクリックのどれでもできる。Delete キーで削除
- 今後: 3D 形状（glTF/STL）の読込、ワーク（製品）と「掴む／離す」ブロック
- `version: 1`（〜rev.62）: `{q1, reach}` 形式。読込時に `CRX.fromLegacy()` で「ツール下向き・水平リーチ一致・
  高さ = J1 原点」の 6 軸姿勢に変換する（元の 2D では高さの情報が無いため）。

## 開発

- ローカル確認: `python3 scripts/serve.py` で `site/` を配信し `http://localhost:8000/simulator/lexxmoma-2d.html`
  を開く。`lexxmoma-2d.html` をダブルクリック（`file://`）で開いても、3D とサンプルを含めて動く
- `python3 site/simulator/build.py`: ダブルクリックで動かすための生成物を作る。STL・サンプル・vendor を変えたら実行して生成物もコミットする
  （CI で作り直した結果と比べる）。生成物は `vendor/three.bundle.js`（Three.js とアドオンを普通のスクリプト 1 本に）、
  `meshes/crx20ia_l.js`（STL を base64 で埋め込み）、`samples/embedded.js`（サンプルの一覧と中身）。file:// では ES モジュールと fetch が止められるため
- テスト: `node --test site/simulator/test/kinematics.test.cjs`
- 変更のたびにヘッダーの `rev.N` を上げる。保存 JSON にも rev が記録される
- 行末は CRLF（`lexxmoma-2d.html`）

## サンプル（`samples/`）

- シミュレーターの「📂 サンプル」ボタン（`samples.js`）が `samples/index.json` の一覧をカードで出し、選んだ JSON を本体の
  `applyLoadedData()` に渡す。カードにはレイアウトの簡易プレビューとサイクルタイム（本体の計算で算出）が出る
- `?sample=<id>`（`&play=1` で再生まで）を URL に付けると起動時にそのサンプルを開く。共有リンクやツアーから使う
- サンプルを足すときは JSON を `samples/` に置き、`index.json` に 1 件追加する。形式は「設定保存」と同じ
- 展示会デモ（`samples/booth-demo.json`）はシミュレーターで作って「設定保存」した JSON をそのまま置いている。直すときも
  シミュレーターで開いて編集し、保存したファイルで差し替える（スクリプトでは生成しない）
