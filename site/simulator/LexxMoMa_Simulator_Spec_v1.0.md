# LexxMoMa 動作シミュレーター 仕様書 v1.0

> 本書はヒアリングで確定した内容のみを記載する（想像による補完は含まない）。
> 数値はスペック値・確定値を区別して明記する。

---

## 1. 目的

- 営業担当者が顧客に対して使うツール。
- 顧客のやりたいこと（工程）に対して、ざっくりどれくらいのサイクルタイムで実現できそうかを確認する。
- ユーザーがロボットの動作を記述すると、その通りに動く。
- 経過時間を表示し、トータル何秒かかっているかを見られるようにする。

## 2. 全体像・前提

- 2D のシミュレーターとする。
- MoMa の車体（ボディ）とアームの両方を動かす。
- 動作の指示はブロックプログラミングのような形で行う（ユーザーがブロックを並べて動作を記述する）。

## 3. 機能要件

### 3.1 動作記述ブロック

| ブロック | 内容 |
|---|---|
| **Move Body** | 車体側を特定の位置姿勢に動かすブロック。位置は事前に登録しておく。 |
| **Move Arm** | アームを特定の位置姿勢に動かすブロック。位置姿勢は事前に登録しておく。 |
| **other action** | カメラ撮像・加工機の動作など、Arm とボディ以外の動作の時間。動作の名前と待ち時間をユーザーが入力できる。 |

### 3.2 時間表示

- 経過時間を表示する。
- トータルで何秒かかっているかを表示する。
- ブロックごとの所要時間も表示する。

### 3.3 位置姿勢の登録機能

- アームとボディの位置を登録できる。
- 座標系：
  - アームの登録座標系は車体相対とする。
  - 車体の登録位置はワールド（環境）座標とする。
- 描画上の操作はキーボードで行う（マウス操作は用いない）：

  | 操作 | 割り当て | 内容 |
  |---|---|---|
  | 車体・前後移動 | 前後キー（↑ / ↓、Shift なし） | 前後に移動 |
  | 車体・回転 | 左右キー（← / →、Shift なし） | 回転 |
  | アーム・1 軸回転 | Shift ＋ 左右キー | 1 軸目の回転 |
  | アーム・伸縮 | Shift ＋ 前後キー | 2・3 軸目により、アーム前方向に伸び縮み |

### 3.4 車体の移動・時間モデル（Move Body）

- 車体は、指示された位置から次の位置まで Dubins path で引いた最短パスを走る。
- ユーザー入力パラメータ：
  - 最小旋回半径（1 つの値が全 Dubins path 計算に共通適用される）
  - 並進加速度
  - 最大並進速度
- 減速度は並進加速度と同値とする。
- 点から点の所要時間は、パス長・並進加速度・最大並進速度から算出する。

### 3.5 アームの動作・時間モデル（Move Arm）

- ユーザー入力パラメータ：各軸の角加速度、各軸の最大角速度。
- 角減速度は角加速度と同値とする。
- 各軸は同時に動く。Move Arm 全体の所要時間は、各軸到達時間の最大値とする。

### 3.6 ブロックの実行順序（順次／並列）

- アームと車体を同時に動かすかどうかは、ブロックの組み方で指定する。
- 順次実行：ブロックを縦に段違いで並べると、順番に動く。

  ```
  ↓
  車体動作
  ↓
  アーム動作
  ↓
  ```

- 並列実行：ブロックを同じ段にまとめて並べると、並列に動く。

  ```
  ↓
  車体動作
  アーム動作
  ↓
  ```

- 並列（同じ段）に置いたブロック群の所要時間は、含まれるブロックの最大値とする。
- トータル時間は、順次段の加算＋各並列段の最大値で算出される。

### 3.7 保存・読込

- 動作シーケンスの保存・読込ができる。

### 3.8 背景描画

- 背景を描ける機能を持つ。
- 直線を描く機能と、消す機能を持つ（この 2 つのみ）。
- 線の色を選べる。

## 4. モデル諸元

### 4.1 車体（ボディ）

- 差動二輪の AGV。
- 車体サイズ：前後 750mm、左右幅 600mm の長方形。
- どちらが前か分かるように、UI 上で判別できるデザインにする（例：矢印、前後が分かる模様 など）。

### 4.2 アーム

- 本来は 6 軸だが、今回は 2D のため 3 軸で再現する（6 軸協働ロボットの 1・2・3 軸を再現するイメージ）。
- 軸方向：
  - 1 軸 … 重力方向
  - 2 軸・3 軸 … 重力に直角方向
- アーム長：FANUC CRX-20 を想定。
  - 参考スペック値：CRX-20iA/L 最大リーチ 1,418mm（FANUC 公表スペック値）。
  - リンク長は 1,418mm を半分ずつ割り振る（各リンク 709mm）。
- 描画表現：
  - 腕（リンク）は長方形、ジョイントは丸で表現する。
  - 上からの俯瞰図とする。
  - 1 軸・2 軸は常に車体中心に位置する。
  - アームは単リンク近似とする。伸び縮みの無理な表示は行わず、3 軸目の描画が正しくできていればよい。
  - 3 軸目のジョイントは、先端から 709mm の位置に描画する。
  - ジョイントの丸は腕（リンク）の幅より少し大きく描く。これにより、ジョイントが重なりで隠れていても位置が見え、姿勢が分かる。

### 4.3 描画の重なり順（俯瞰表現）

- 俯瞰図のため、構造的に下側のものは上側の描画に隠れるようにする。
- 車体はアームより下にあるため、常に隠れる側とする。

## 5. 非機能要件

- アプリは HTML 1 ファイルで作成する。

## 付録 A. ユーザー入力パラメータ一覧

| 対象 | パラメータ | 適用範囲 |
|---|---|---|
| 車体（Move Body） | 最小旋回半径 | 全 Dubins path 計算に共通 |
| 車体（Move Body） | 並進加速度（＝減速度） | 車体移動 |
| 車体（Move Body） | 最大並進速度 | 車体移動 |
| アーム（Move Arm） | 各軸の角加速度（＝角減速度） | 各軸 |
| アーム（Move Arm） | 各軸の最大角速度 | 各軸 |
| other action | 動作の名前 | 各ブロック |
| other action | 待ち時間 | 各ブロック |
| 背景描画 | 線の色 | 描画線 |

## 付録 B. 主要な設計判断（確定）

- 時間集計：順次＝加算、並列段＝含まれるブロックの最大値、Move Arm＝各軸の最大値。
- 座標系：アーム＝車体相対、車体＝ワールド座標。
- アーム描画：単リンク近似。1・2 軸は車体中心固定、3 軸目ジョイントを先端から 709mm に描画。伸び縮みの誇張表示はしない。
- 操作系：キーボードのみ（マウス不使用）。車体＝矢印キー、アーム＝Shift＋矢印キー。
- 実装形態：HTML 1 ファイル。
