# LexxMoMa 費用対効果（ROI）計算ツール

LexxMoMa トライアル導入の社内稟議に添付できる「投資回収年数」を、お客さま側の担当者がご自身で算出するためのツールです。
配布物は **`dist/lexxmoma_roi.html` の1ファイル**。ダブルクリックで開き、オフラインで全機能が動作します（外部通信なし）。

## 使い方（お客さま向け）
1. `lexxmoma_roi.html` を Edge または Chrome で開く
2. 左の「初期投資」4欄と「年間ランニング費」に、お見積書の金額（万円）を転記する
3. 右に投資回収年数・累積効果・グラフが即時表示される
4. 下の **Excelダウンロード** / **サマリー文をコピー** / **印刷**（A4縦1枚）で稟議書へ添付する
5. 保存した Excel は **Excel読み込み**（または画面へドラッグ＆ドロップ）で入力欄に戻せます（シナリオA/B・稟議基準も復元）

### Excel ファイル（`LexxMoMa_ROI_{シナリオ名}_{日付}.xlsx`）
- **「入力・計算」シート**：黄色のセルに入力すると、**Excel 単体で**投資回収年数・累積効果・NPV・年次表まで計算されます（計算式はツールと同じ。稟議基準で緑・黄に色分け）。モード・直数・評価期間・NPV はプルダウン
- **「シナリオ比較」シート**：シナリオ A/B を保存しているときだけ付きます（保存時点の値。再計算はしません）
- 初期値のまま（価格欄は空白）ダウンロードすれば入力用の雛形になります。社内の標準値（人件費・直数など）を入れたものを手元に置いておく使い方を想定しています
- 非表示の E 列（キー）は変更しないでください。旧形式の `.xls` は読めないので `.xlsx` で保存してください
- 以前このツールで保存した **CSV** も「Excel読み込み」で読み込めます（CSV の出力は廃止）

- 「精緻」モードに切り替えると、人件費・稼働・初期投資・ランニングを内訳で入力でき、付加効果（不良・ラインストップ低減）や NPV も扱えます。切り替えても値は失われません。
- ⚙（歯車）から稟議基準（メーターの緑・黄のしきい値）を変更できます。
- シナリオ A/B に保存すると、比較表とグラフの2系列重ね描きができます。

## 営業向け：事前入力済みリンクの作り方
入力内容はすべて URL の `#v1=…` に保持されます。お客さまの見積額を入れた状態で渡す手順：

1. `lexxmoma_roi.html` を自分のPCで開く
2. 初期投資4欄・ランニング費・直数など、見積に合わせて入力（シナリオ名に案件名を入れると Excel のファイル名にも反映）
3. **URLをコピー** を押す → `file:///…/lexxmoma_roi.html#v1=XXXX` がクリップボードに入る
4. お客さまへは HTML ファイルと **`#v1=XXXX` の部分**を渡す。お客さまはファイルを開いた後、アドレスバーの末尾に `#v1=XXXX` を貼り付けて Enter で復元される
   - もしくは、ファイル名を変えずに同じフォルダに置いてもらえば、コピーした URL をそのままお伝えできます

※ 価格の初期値は空白です。配布物そのものに当社価格は含まれません。

## 開発
```
lexxmoma-roi/
├── dist/lexxmoma_roi.html   # 配布物（ビルド生成）
├── src/                     # index.html / calc.js / ui.js / csv.js / xlsx.js / styles.css
├── test/calc.test.js        # node --test
├── build.js                 # src → dist（Node）
├── build.py                 # 同処理の Python 版（Node が無い環境向け）
├── CLAUDE.md / SPEC.md / README.md
```

```bash
node --test          # テスト
node build.js        # ビルド
python build.py      # Node が無い場合のビルド
```
