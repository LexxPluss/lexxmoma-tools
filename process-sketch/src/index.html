工程シミュレーター(2D)の使い方

工程のレイアウトを描いて、1日に何個できるか・人の手間がどれだけかかるかを確かめるツールです。

ひな形から始める 近い工程を選んで、名前と時間を書き換えるのが早道です(今の図は置き換わります)

やりたいことから探す 押すと、画面のどこで操作するかを示します

くわしい操作説明・設備の考え方・キー操作
  1. 置く … 左の部品をクリック→図の上をクリック(ドラッグでも可)。「ひな形」から始めると早いです。
  2. つなぐ … 設備を選ぶと右端に出る ● を次の設備へドラッグ。モノの流れの矢印ができ、近くの作業者が運び手になります。
  3. 工程の中身を書く … 設備を選ぶと右に「工程カード」。① 前工程から入れるもの(名前・数) ② 出すもの(名前・数)と次工程 ③ 時間(自動運転の秒・人の作業の秒)を入れます。
  4. 面を決める … 設備の縁の 入(入れる面)・出(取り出す面)・足あと(作業する面)は、つないだ相手の方向へ自動で向きます。変えたいときは印をドラッグして別の面で離すだけ。「出」を「入」の上へ重ねると1つの「入出」口(同じ口で入れて取り出す)にまとまります(小さい設備で同じ面なら自動で1つ)。Shift+ドラッグで分けられます。
  5. 通路を描く … 左の「通路(歩く所)」を選び、角をクリックしていくと多角形で囲めます。人・LexxMoMa は通路の中だけを歩きます(立ち位置=面の正面が通路に入るように)。「立入禁止」も同じ要領です。
  6. 動かす … 下の「▶ 動かす」。作業者は面の正面に立ち、設備の方を向いて取り出し・投入・作業をします。向きを変えるにも時間がかかります(台車を押していると遅い)。歩いた跡(導線)が残ります。
  7. 計算して比べる … 下の「1日分を計算」で、1日にできる数(必要数に届くか)と人の作業時間が出ます。結果の「LexxMoMa に任せる作業を選ぶ」で、運搬や設備の作業を LexxMoMa に任せたときと比べられます。1日の稼働時間・休憩・必要数は、何も選んでいない時の右の欄で入れます。
  8. 持っていく … 「検討シートを作る」で、レイアウト図・設備一覧・流れ・歩行距離・自動化候補・確認事項を1枚に。

設備の考え方(細かくしすぎない)

加工A → B形が変わる(切る・曲げる・成形・塗る…)
溶接・接着・組立A + B → C2つ以上が1つになる。入ってくる矢印の数だけ部品を待つ
検査A = Aモノは変わらない。NG率を入れると不良が抜ける
手作業台A → B人が付いている間だけ進む
仮置き・棚ためる中継・バッファ
台車・コンテナまとめて運ぶ矢印の「運び方」で選ぶ。人が取りに行き、押して運び、置いて帰る
