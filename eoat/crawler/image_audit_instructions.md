# 画像の点検(品質ループ。サブエージェント向け)

公開中の画像を 20 枚ずつ並べたシート(`eoat/data/image_audit/sheets/i_NNN.jpg`、黄色の番号 1〜20)を見て、**事例の写真として使えない画像**を拾う。

## bad(外す)
- 人物が主役(インタビュー・集合写真・握手・展示会の来場者)でロボットもハンドもワークも写っていない
- ロゴ・文字だけのバナー・表紙・図表・グラフ・フローチャート・画面のスクリーンショット
- 事例と関係のないイメージ写真(果物の木・畑・トラクター・風景・街並み・建物の外観・オフィス)
- 動画の再生ボタンが描かれた画像・動画への誘導画像
- 製品のカタログ写真で、ロボットにもハンドにも関係しない物(楽器・家電・食品だけ など。ワークだけの写真は ok 扱いにしない)

## ok(残す)
- ロボットのアーム・ハンド(グリッパ・吸盤)・ワークを扱う場面のどれかが写っている(遠景のセルでもロボットが見えれば ok)
- ハンドの製品写真・CG(ハンドそのものが写っていれば ok)
- ロボットが置かれた設備の写真(パレタイズセル・工作機械とロボット)

迷ったら ok(誤って良い画像を外すほうが損)。
画像が読み込めなかったシートは書かない(見ていないものを判定しない)。

## 出力
`eoat/data/image_audit/out/i_NNN.json` に、bad の番号だけを配列で:
```json
{"bad": [{"n": 3, "why": "人物の集合写真"}, {"n": 17, "why": "ロゴのバナー"}]}
```
bad が無ければ `{"bad": []}`。
