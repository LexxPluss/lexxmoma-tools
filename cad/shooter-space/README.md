# シューターの省スペース検討（CAD）

TP規格コンテナとシューター（部品供給棚）を寸法から作り、**同じ箱数を置くのに必要な床面積**を比べるための設計一式です。
オープンソースの CAD ライブラリ **CadQuery**（形状エンジンは FreeCAD と同じ Open CASCADE）で作り、STEP で書き出します。
STEP は **FreeCAD** で開いて、そのまま修正・図面化できます。

検討の結果は [REPORT.md](REPORT.md) にまとめています。

## 作り直し方

```sh
pip install cadquery matplotlib     # 初回だけ（Linux で陰影画像を作るときは libosmesa6 も必要）
cd cad/shooter-space
python3 build.py                    # out/ に STEP・画像・寸法図・部材表を出す（1分ほど）
```

## ファイル

| ファイル | 内容 |
|---|---|
| `params.py` | すべての寸法と隙間のルール。出典つきの値と仮値を分けて書いている |
| `tp.py` | TP規格コンテナの3Dモデル（外寸・内寸は掲載値、取っ手穴・底の嵌合部などの細部は簡略） |
| `parts.py` | Φ28パイプ・ジョイント・ローラーレール・ストッパーと、部材の数え上げ |
| `shooter.py` | 段の並びを渡すと、隙間のルールを満たす最小の高さで段を積み、棚を組み立てる |
| `variants.py` | 比較する案（A 従来型・E 本案） |
| `reach.py` | MoMa がフック式ハンドで TP 箱を水平に出し入れできる高さと停止距離を計算する |
| `optimize.py` | 列数・奥行きの箱数・空箱返却の置き方を総当たりして、条件を満たす中で床面積が最小の案を探す |
| `params_local.py` | 社内の実機値（任意・git に入れない）。あれば `params.py` の仮値を上書きする |
| `build.py` | 書き出し（STEP・陰影画像・寸法図・部材表・summary.json） |
| `out/shooter_variants_step.zip` | 比較する案の組立 STEP（FreeCAD で開く） |
| `out/TP-*.step` | TP コンテナ単体の STEP |
| `out/*_drawing.png` | 側面の断面と、ライン側から見た正面の寸法図 |
| `out/*_aisle.png`, `out/*_line.png` | 通路側・ライン側から見た陰影画像 |
| `out/*_bom.csv` | 部材表（パイプの長さと本数・レール・ローラー・ストッパー） |
| `out/footprint_compare.png` | 案の床面積を真上から並べた図 |
| `out/optimize.csv` | 総当たりの結果 |
| `out/reach_chart.png` | 高さごとに止まれる距離（MoMa の届く範囲）と本案の段 |

## 座標と単位

- 単位は mm。X＝棚の幅（間口方向）、Y＝奥行き（0＝ライン側の面、＋Y＝通路側）、Z＝高さ（床＝0）。
- 段の高さは「箱を置く面」の床からの高さ。ライン側（Y=0）と通路側（Y=奥行き）の両方を出している（傾斜のため）。

## 段を積むルール（shooter.py）

下の段の箱の上端から、上の段の構造（レール＋受けパイプ＝54mm）の下面までの空きを、段の種類ごとに決めている（`params.GAP`）。

| 下の段の種類 | ライン側の空き | 通路側の空き | 理由 |
|---|---|---|---|
| 取り出し | 100mm（仮） | 60mm（仮） | ライン側は手を入れて部品を取る。通路側は箱を入れる |
| 空箱返却 | 60mm（仮） | 60mm（仮） | 空箱を置く・取り出す |
| 予備在庫 | 15mm（仮） | 60mm（仮） | 通路側からだけ出し入れする（ライン側は閉じ板） |

取り出し段は、置き面が 700mm 以上、ライン側の箱の上端が 1500mm 以下という条件を付けている。
