# みんなのアイデアボード — 保存先のセットアップ

見学ツアー SPOT 5(ご相談カウンター)の投稿を、全員分 1 か所にためるための設定です。
設定するまでは「テストモード」で動きます(投稿はその人のブラウザにだけ保存され、ボードには記入例と自分の投稿だけが出ます)。

## なぜ GitHub ではなく Google スプレッドシートか
- GitHub Pages は置いたファイルを配るだけで、閲覧者からの書き込みを受け取れない
- GitHub API で書き込むにはトークンが必要。ページに埋め込むと誰でも抜き取れて、リポジトリを書き換えられてしまう
- GitHub Issues / Discussions への投稿は、閲覧者全員に GitHub アカウントとログインが必要(お客さま向けには不向き)

→ ページは GitHub Pages のまま、投稿の保存先だけ Google Apps Script(無料・ログイン不要で受付)にする。
データは LexxPluss の Google アカウントのスプレッドシートに1行ずつたまり、そのまま閲覧・非表示にできる。

## 手順(10分ほど)
1. Google ドライブで新しいスプレッドシートを作る(名前例: `LexxMoMa見学ツアー_アイデアボード`)
2. メニュー「拡張機能 > Apps Script」を開き、最初からあるコードを消して `apps-script.gs` の中身を貼り付けて保存
3. 右上「デプロイ > 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - 「デプロイ」→ 初回は権限の承認を求められるので許可する
4. 表示された「ウェブアプリの URL」(`https://script.google.com/macros/s/…/exec`)をコピー
5. `library/materials.js` の `board.endpoint` に貼り付けて保存

```js
board: { endpoint: "https://script.google.com/macros/s/xxxxxxxx/exec" },
```

6. 見学ツアーを開き、ボードの「テストモード」表示が消えていれば完了。最初の投稿でシート `posts` が自動で作られる

> 会社の Google Workspace の設定で「アクセスできるユーザー: 全員」を選べない場合は、管理者に匿名アクセスの許可を依頼するか、
> 個人の Google アカウントで同じ手順を行ってください。

## 運用
- シートの `status` 列: `public`=ボードに表示 / `pending`=確認待ち(表示しない) / `hidden`=非表示
- 表示をやめたい投稿は `status` を `hidden` に書き換えるだけ(削除しなくてよい)
- 会社名・メールアドレス・電話番号・所在地らしき表現を含む投稿は、自動で `pending` になり表示されない(`flags` 列に `pii?`)。
  内容を確認して問題なければ `public` に、そうでなければ `hidden` に
- 全件を人が確認してから出したい場合は、コード先頭の `AUTO_PUBLISH` を `false` にして再デプロイ
- コードを直したら「デプロイ > デプロイを管理 > 編集 > 新バージョン」で更新(URL は変わらない)

## 集めている項目(個人・法人を特定する項目は持たない)
| 列 | 内容 |
|---|---|
| process / processText | 使えそうな工程(選択)と、具体的な作業のイメージ(120字まで) |
| shift / industry | 稼働イメージ・業種(任意の選択肢) |
| reaction / impression | ツアーの感想(4択)と、印象に残ったこと(200字まで) |
| plus / plusText | あったらうれしいこと(選択)と自由記入(120字まで) |

IP アドレス・端末情報・顧客コード(?c=)は保存しない。投稿画面では「LexxPluss はこの投稿を営業情報として取り扱わない」ことを明示している。
